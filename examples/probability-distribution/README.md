# Example: learning probability distributions

This sample shows the durable state after an initial diagnostic. It is intentionally small: only the active goal, nearby prerequisites, one misconception, and one next-session branch are represented.

## Learner request

```text
Use $learn-by-ai to help me distinguish random variables, distributions,
densities, and point probabilities, then apply them independently in simulation.
I can calculate with common distributions but often confuse density values with probabilities.
```

## What the diagnostic found

- The learner can identify a random variable and compute routine density expressions.
- The earliest breakpoint is object confusion: treating a density value as probability mass.
- The active route pauses broad distribution families and repairs the relationship among random variables, induced distributions, densities, and interval probability.
- The opening question asks for a discriminating comparison rather than another self-rating.

## Files

- `project.yaml`: current goal and route.
- `resource-index.yaml`: an accessible notes source and an unavailable referenced textbook.
- `knowledge-graph.yaml`: two active concepts and one prerequisite edge.
- `learner-state.yaml`: separate conceptual, standard-problem, and transfer evidence.
- `evidence.jsonl`: the diagnostic attempt that justifies the state.
- `checkpoint.md`: the exact handoff to a new conversation.

This is an illustrative state snapshot, not a complete probability course.
